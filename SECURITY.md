# Security Policy

## Supported versions

Security fixes are applied to the latest version on the default branch. Older snapshots and third-party repackaged copies are not maintained.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through the maintainer contact options on the [GitHub profile](https://github.com/xuyunfeng394175). Do not open a public issue until the report has been assessed and a coordinated disclosure date has been agreed.

Include the affected version, impact, reproduction steps, and a minimal proof of concept. Do not send real credentials, cookies, tokens, browser profiles, private media, private transcripts, or other people's personal data. Use synthetic files and redact account identifiers and local paths.

This project automates a third-party web service. Reports about Qianwen itself should be sent to the service owner through its official security channel. Reports about an AI client's browser or command-execution implementation should be sent to that client's vendor.
